## 선정 및 제작 절차

네 항목을 각 1~5점으로 평가: 자연스러운 시작·끝, 과장 없는 감정, 인물 간 구분, 반복 피로가 적음. 실제 녹음은 자연스러움의 기준이며 해당 화자의 모든 배역 발성을 이미 확보했다는 의미가 아니다.

음색을 선택한 후에만 최소 6개/인물의 완결된 발성을 새로 제작한다. ElevenLabs 선택 시 계정의 유료 상태·잔여 한도·모델 이용 조건을 확인한다. 생성 날짜·voice ID·모델 ID·구독 증거·generation/history ID·원본 해시를 저장한다. API 키는 저장하지 않는다.

[ElevenLabs 공식 조건](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform): 무료 생성물은 상업 이용 불가. 유료 생성물도 베타 서비스 등 제한을 확인한다. 공개 미리듣기는 게임 제작 음원으로 간주하지 않는다.

승인 음원만 `sample/game/audio/voices.json`에 연결한다. 배역별 `approved`, `commercial_evidence`, 중복되지 않는 6개 이상의 `clips`를 갖춰야 한다. 실제 청취 승인 전에는 음성 완성으로 표시하지 않는다.
