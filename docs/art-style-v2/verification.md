# 승인 그림체 적용 검증 — 0.2.0

2026-10-03. 승인 이미지: `miran-classic-otome-bust-preview.png`.

- 승인된 미란 원본을 평상 표정으로 그대로 복사했다. SHA-256 및 바이트 동일 확인.
- 미란 4종·세란 3종·옥녀 2종, 정원·복도, CG01 총 12개 적용. 캐릭터 PNG 9개 모두 1086×1448 RGBA이고 투명 알파를 확인했다. `image-validation.json` 참조.
- 캐릭터 상반신 구도에 맞춰 게임 표시 높이를 미란 1050, 세란 1075, 옥녀 1015로 조정했다. 두 인물 정원과 세 인물 복도에서 얼굴과 대화창 겹침이 없음을 실제 엔진 캡처로 확인했다.
- 제목 화면 안내 문구와 종료 버튼 겹침을 수정했다. 새 제작 단계에 맞춰 음색 선택 전이라는 문구를 정리했다.
- 원문 S01~S02 122블록의 화자·문장·순서 검사를 포함한 7개 콘텐츠/발성 정책 검사 통과.
- 엔진 완주·저장/불러오기·기록·메뉴·자동 진행·읽은 대사 스킵 검사 19개 assertion 및 발성 라우팅 검사 8개 assertion 통과. 재검사 중 음성 테스트가 한 차례 대사를 지나쳐 timeout되어 해당 테스트의 자동 진행과 스킵 초기 상태를 명시한 뒤 전체 회귀 검사를 다시 통과했다. 게임 본문 동작은 변경하지 않았다.
- 테스트 모드가 아닌 일반 실행도 확인했다. VSync 0 유지, Enter·Esc·전체 화면 전환·음악 시계 진행 통과. 최대 관측 출력 지연 0.147초 미만. `native-playback.log` 참조. 30초의 자동 검사와 전체 대사 기능 검사이며 사람의 6~9분 정독을 대신하지 않는다.
- Linux/Windows 빌드와 패키지 자산 해시·누락·테스트 파일 제외 검사 수행. Windows는 실제 실행 환경이 없어 파일 검사만 한다.
- 이전 미술은 `before-approved-style`에 보존했고, 신규 생성 파일 원본·프롬프트·참조 스냅샷 해시는 `production-manifest.json`에 기록했다. 생성 이미지를 다른 프로그램으로 보정하지 않았다.
- 기존 Linux VSync 우회, 음악·환경음, 대본은 유지했다. 새로운 사람 발성은 아직 포함하지 않는다.
