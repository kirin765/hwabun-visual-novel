## 실행 증거

- `final-tests.log`: 콘텐츠/정책 단위 테스트 7개, Linux 엔진 플레이 2개, 발성 라우팅 1개.
- `linux-package-tests.log`: 압축 해제한 배포본의 실제 엔진 검사.
- `package-verification.json`: 두 패키지 SHA-256, 엔트리 수, 자산 22개(이미지 12/음원 8/글꼴 2) 해시 대조.
- `audio-decode-check.json`: 8개 OGG 디코딩·음량 분석.
- `../sample/tests/screenshots/`: 제목, 정원, CG, 놀람, 복도, 긴 속말, 설정, 기록, 종료 화면.
- `build.log`: Ren’Py lint와 빌드 결과. 개발용 lint는 테스트 대사 4블록을 추가로 셈하므로 126블록으로 표시한다. 배포 패키지에는 테스트 RPY/RPYC를 제외하여 본문 122블록만 포함한다.

## 0.1.1 최종 재검사

2026-10-03: 콘텐츠·발성 정책 7개 검사, 엔진 회귀 검사 27개 assertion 통과. 일반 원본 실행과 압축 해제한 Linux 배포본 모두 `swap interval: 0 frames` 확인, Enter·Esc·전체 화면 전환·음악 시계 진행 통과. 최대 관측 출력 시간은 각각 0.145초 / 0.141초 미만. 사용자 비교 실행도 정상 진행 확인. 진단 도구의 주기적 스택 출력에서 생긴 별도 크래시는 해당 기능 제거 뒤 재검증했다. 자세한 원인과 증거는 [정지 조사](freeze-diagnosis/README.md)에 기록했다.
