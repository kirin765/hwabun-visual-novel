# 『화분』 배경 고증과 제작 기준

조사일: 2026-10-03. 범위: 제공된 원문 TXT, 기존 각색·장면·인물 설정, 공공기관 자료. 원작의 묘사와 실제 역사, 제작을 위한 창작 결정을 구분한다. 이 문서는 고증의 1차 심화 결과이며 사진·도면에 의한 모든 소품의 형태 검증이 끝났다는 뜻은 아니다.

## 1. 시대와 장소의 기준

- **시대:** 1930년대 후반 일제강점기를 제작 기준으로 유지한다. 『화분』의 1939년 출간은 확인되지만 출간 연도가 곧 사건의 연도라는 뜻은 아니다. 화면에 ‘1939년’ 날짜를 확정해서 넣지 않는다. [한국학중앙연구원 작품 항목](https://encykorea.aks.ac.kr/Article/E0064627)
- **주 무대:** 평양 교외 모란봉 가까운 주택지의 푸른 집과 평양 시내. 원문 16~20행의 모란봉, 466~470행 부근의 만수대·측후소가 위치 단서다. 작품 항목도 평양 교외라고 설명한다. 경성을 기본 도시로 삼지 않는다. [원문](/home/giwan/Downloads/hwabun_이효석/이효석-화분.txt), [작품 항목](https://encykorea.aks.ac.kr/Article/E0064627)
- **여행지:** 도쿄, 관북 주을 산골의 노비나 마을, 결말의 하얼빈. 주을·노비나는 원문 3161~3168행에 직접 명시된다. 노비나의 실재 범위·집 배치·건축 양식은 별도 사료 대조가 필요하다. 문학 속 명칭 확인을 곧 실제 촌락 전체의 복원으로 취급하지 않는다.
- **계절:** 시작은 5월, 이후 여름 피서, 마지막 별장 후일담은 늦여름·초가을과 첫 난방으로 이어진다. 원문 5행과 4990~5077행. 전 장면을 같은 여름 조명·같은 의상으로 통일하지 않는다.

## 2. 증거 등급

| 구분 | 의미 | 제작에 사용하는 방법 |
|---|---|---|
| 원문 확인 | 이 작품에 실제 등장하는 묘사 | 각색에서 바꾸면 변경이라고 표시 |
| 역사 확인 | 기관의 사료·유물 또는 연구로 실재가 확인됨 | 지역·연도·건물의 적용 범위를 지킴 |
| 제작 추정 | 구성상 필요한 미확정 형태 | 특정 실재 건물·기종의 복원이라고 부르지 않음 |
| 각색 변경 | 원문과 의도적으로 다름 | 서사적 이유와 영향을 기록 |

기관 해설도 당시 사진·도면 자체와는 구별한다. 원문은 문학적 1차 자료이지 실제 주소나 운행 시간표의 증명서가 아니다. 원문 TXT의 오탈자와 단위는 초판 이미지 대조 전까지 역사적 사실로 전환하지 않는다.

## 4. 실재 근거와 시각 자료

### 평양의 상업 공간

평양의 백화점 이용 자체에는 역사적 근거가 있다. 국사편찬위원회는 화신의 평양 지점 개관을 1935년 12월 1일로 설명한다. 미나카이도 평양에 지점을 설치했다. 그러나 이 자료들은 원작 백화점의 식당·승강기·창밖 전망과 실재 건물의 일치를 입증하지 않는다. 경성 화신 본점의 층수와 시설을 평양 지점에 옮겨 쓰지 않는다. [화신의 지방 진출](https://contents.history.go.kr/front/km/view.do?levelId=km_016_0060_0030_0040), [미나카이 지점망](https://contents.history.go.kr/front/km/view.do?levelId=km_020_0060_0010_0020)

### 전차의 동시대 기록

1923년 5월 30일 동아일보의 평양전차 개통기념전람회 기사와 같은 해 7월 『개벽』의 기록은 평양 전차의 동시대 1차 자료다. 원작의 전차 이동을 뒷받침한다. 정확한 개통일·장면의 정류장·차량 색상·노선은 이 기록만으로 확정하지 않는다. [동아일보 기사 레코드](https://db.history.go.kr/modern/level.do?levelId=npda_1923_05_30_v0004_0840), [개벽 일지](https://db.history.go.kr/contemp/level.do?levelId=ma_013_0360_0140&types=o)

### 모란봉의 지형

국립중앙박물관은 **건판 005975, ‘평남 평양 모란봉 전경’, 1922년** 사진을 제공한다. 지형·구릉·당시 경관을 확인할 1차 자료다. 이야기보다 이른 사진이므로 1930년대 후반 거리 시설이나 집의 실제 위치까지 입증하지는 않는다. 같은 검색에 나오는 1941년 회화나무 사진이나 촬영 연도 미상의 항공사진은 각각 날짜를 따로 표시한다. 사진의 지형과 원문의 집 전망을 대조한 뒤 배경 구도를 결정한다. [국립중앙박물관 유리건판 목록](https://www.museum.go.kr/dryplate/search_more.do?ids1=E&ids2=E02&ids2_title=%EC%9E%90%EC%97%B0&keyWord=%ED%8F%89%EC%96%91&sepatator=ids)

### 비교 자료의 적용 범위

서울역사박물관의 1930년대 경성 설명은 백화점·극장·전차와 식민지 도시의 계층 차이를 설명한다. 평양 거리 복원에는 직접 근거로 쓰지 않는다. 현마 집안의 소비 생활을 조선인 모두의 일상으로 확대하지 않는 비교 맥락에 한정한다. [근대도시, 경성](https://museum.seoul.go.kr/www/board/NR_boardView.do?bbsCd=1182&seq=20221212111358396&sso=ok)

## 5. 복식과 계층

1930년대 양장·구두와 한복의 병존은 국사편찬위원회 자료에서 확인된다. 따라서 양장을 무조건 시대착오로 볼 수는 없다. 다만 미란의 크림 블라우스·옥색 치마·가디건의 조합, 세란의 색상, 특정 치마 길이·깃·여밈·굽은 현재 창작 디자인이다. 평양의 같은 연대 사진이나 의복 유물 대조 없이 ‘고증 완료’라고 표시하지 않는다. [구두와 복식에 관한 당대 인용·해설](https://contents.history.go.kr/mobile/km/view.do?levelId=km_009_0090_0030_0020)

특히 원문 **4497행은 미란의 짙은 색 저고리**를 언급한다. ‘미란은 항상 양장’은 원문 재현이 아니다. 기본 양장을 유지한다면 한복 착용 장면도 마련하거나, 복식 일관화를 위한 각색이라고 기록한다. 옥녀의 치마폭은 2150행, 남성의 양복은 1137·4499행에서 확인된다. 재력가·교사·집안 노동자의 옷을 같은 비싼 소재와 장식으로 통일하지 않는다. 정확한 재료와 가격은 미확정이다.

여학교 졸업 직후라는 원작의 조건과 ‘21세, 졸업 후 2년’이라는 각색 조건도 구별한다. 특정 학교 교복, 현대 세일러복이나 학생증을 새로 넣지 않는다.

## 6. 통신·음악·날씨의 주의점

원문 546행의 라디오 기상특보, 608행의 교향곡, 1798~1828행의 방송 피아노와 신문 라디오란, 3190~3289행의 장거리 전화는 작품의 생활상에 직접 근거가 있다. 실제 방송 편성·방송국·호출부호·수신기 모델은 아직 확인하지 않았다. 빈티지 목제 라디오라는 분위기만으로 다이얼과 상표까지 고증했다고 볼 수 없다.

원문 기상 문구에 등장하는 ‘시속 약 이십 미터’는 단위가 이상하므로 초판 대조 대상이다. 이를 현대 기상 수치로 계산하거나 그대로 전문 방송의 정확한 고증 문구로 쓰지 않는다. 폭풍우 장면을 1939년 특정 날짜의 실제 기상 사건이라고 정하지 않는다.

축음기 음반은 당대 음반 형태·라벨 자료를 확인한 후 그린다. LP, 카세트, 현대 스테레오 장비를 넣지 않는다. 새로 작곡한 게임 배경음악은 당시 실재 연주·방송 복원이라고 설명하지 않는다.

## 8. 다음 제작 전에 필요한 자료

1. 평양의 1930년대 지도와 거리 사진을 같은 구역끼리 비교해 BG03 구도·전차 형태·가공 간판을 확정한다. 현대 평양 지도와 경성 사진으로 대체하지 않는다.
2. 백화점 실재 사진·층별 안내·당대 광고를 확보하여 원작의 4층 식당과 비교한다. 건물 동일성이 확인되지 않으면 이름 없는 원작 공간으로 남긴다.
3. 평양 출발 도쿄행 항공 시간표·항공사 광고·공항 사진을 확보한다. 기종과 경유지는 그 뒤 결정한다.
4. 주을·노비나의 당대 지도·사진·여행 기록을 찾아 산길, 별장, 온천과의 관계를 검증한다. 소설의 거리 단위를 지도상의 정확한 거리로 환산하지 않는다.
5. 평양 또는 적용 가능한 연대·계층의 복식 사진과 의복 유물을 확보해 깃·여밈·소매·치마·구두를 확인한다.
6. 초판 이미지로 전화 대목, 만수대 측후소, 기상 단위, 주택 면적 표현을 대조한다. 제공 TXT와 공개 전사본만의 일치는 독립된 판본 교정이 아니다.

각 자료는 기관, 자료명, 소장번호, 촬영·제작 연도, 적용 장면, 확인 가능한 형태, 확인 불가능한 내용을 기록해야 한다. 이 항목들이 남아 있는 동안 최종 배경 고증 완료라고 표시하지 않는다.
