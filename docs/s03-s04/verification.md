# S03–S04 구현·검증

2026-10-03 / 0.3.0-episode1

## 포함 범위

S01–S04의 대사·속말 415블록을 각색 대본과 문구·순서까지 대조했습니다. C01은 A/B 각각 6블록 후 공통 합류하므로 한 경로의 표시량은 409블록입니다. 전체 원문 11,162자에 따른 읽기 추정은 약 20–32분이며 실측 플레이 시간은 아닙니다.

손님 방문, 거리, 식당, 영화관, 폭풍우 아파트, 촛불 CG와 새벽을 연결했습니다. 신규 이미지 11장, 합성 환경·효과음 7개를 추가했습니다. 미란은 외출·거리에서 겉옷을 입고 실내에서는 기존 의상으로 돌아갑니다. 캐릭터 음원은 추가하지 않았고 게임 중 발성 채널 무음을 확인했습니다.

## 확인

- Python 내용·자산·발성 스케줄러 검사 7개 통과.
- Ren’Py 전체 A 경로 완주, B 경로 자동 진행/읽은 대사 스킵, S03 바로 시작과 S04 저장·복원·완주 통과.
- 저장 복원 후 선택 결과, 음악·환경 채널과 대사 위치 확인. 복원 후 기록 화면 열기·닫기 및 계속 진행 확인.
- 발성 채널 취소 검사 통과. 검사에서 사용한 기존 합성 신호는 사람 목소리가 아니며 신규 캐릭터 음원을 제작하지 않았음.
- Ren’Py lint 오류 없음. 대사 통계 419는 테스트 전용 4블록을 포함함. 테스트 스크립트는 배포에서 제외함.
- 이미지 총 23 PNG, 음원 총 16 Ogg, 한국어 글꼴 2개. 해시 및 배포 패키지 검사는 `docs/package-verification.json` 참조.
- 제목·홀·선택지·거리·식당·영화관·아파트·촛불·새벽 화면은 `sample/tests/screenshots`에 보관.

## 검증 한계와 후속 미술

Linux 엔진 테스트는 dummy 오디오 장치에서 실행했습니다. 실제 청취 품질과 Windows 직접 실행은 이번 자동 검사에서 판단하지 않았습니다.

기존 승인 얼굴·복장을 유지한 플레이용 시안이며 한복 중심 미술의 최종판은 아닙니다. 별도 감정 표정 일부는 평상 표정으로 대체했습니다. 거리의 비와 식당의 어두워짐은 색조·화면 효과로 처리하며, 아파트 촛불·새벽은 별도 생성 배경을 사용합니다. 건축·소품·조명의 세밀한 역사 고증은 추가 검토가 필요합니다.

메인곡은 사용자 MP3와 공식 Kevin MacLeod 배포 파일의 해시 일치를 확인해 출처를 기록했습니다. 식당·축음기·라디오의 독립 선곡은 메인곡으로 임시 연결했습니다. 캐릭터별 의상 목록과 장면별 CG 확장은 `docs/korean-art-direction.md`의 방향을 따릅니다.
