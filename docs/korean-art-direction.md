# 한국의 생활문화가 드러나는 미술 조정 지침

2026-10-03 사용자 지시 반영. **현재 단계는 미술 방향과 후속 제작 기준의 조정이며 이미지 생성·수정 실행은 하지 않는다.** 기존 승인 이미지, 생성 프롬프트·매니페스트와 패키지는 제작 이력으로 유지한다. 다음 제작 시 이 지침을 적용한다.

## 전체 방향

승인된 여성향 비주얼 노벨의 선화·표정·채색을 바탕으로, 인물의 복식과 공간의 생활문화에서 1930년대 후반 평양의 한국적 성격을 강화한다. 원문의 서구 음악·영화·양옥·양장과 한국의 일상이 공존하는 모습을 유지한다. 한국적 색채를 전통 문양·오방색·궁궐 장식의 일괄 추가로 해결하지 않는다. 시대와 지역의 근거는 [배경 고증](historical-setting.md)을 따른다.

## 인물과 복식

| 인물 | 다음 이미지 제작에 적용할 방향 |
|---|---|
| 미란 | 집·정원의 기본 의상을 크림색 저고리와 옥색 개량 한복 치마로 조정한다. 깃·동정·고름과 저고리·치마의 관계가 읽히도록 한다. 블라우스와 치마는 시내 외출·음악 수업용 추가 의상으로 남긴다. 후반에는 원문의 짙은 색 저고리 단서를 반영한다. |
| 세란 | 기존 가지색 저고리·크림색 치마를 발전시킨다. 미란과 소재감·옷의 정돈·실루엣을 구분하며, 장식의 양으로만 부유함을 표현하지 않는다. |
| 가야 | 비둘기색 저고리와 차분한 치마의 개량 한복을 기본으로 구체화한다. 음악을 배우는 여성의 단정한 차림으로 표현한다. 가족 재산이 확인되지 않았으므로 고가 장신구를 추가하지 않는다. |
| 옥녀 | 저고리·남색 치마와 작업 앞치마를 유지한다. 노동에 필요한 움직임과 사용감을 표현한다. 일본식 메이드복 형태로 바꾸지 않는다. |
| 현마·단주·영훈 | 직업과 원문에 맞는 양복·셔츠·조끼를 유지한다. 현마의 재력, 단주의 후원받는 차림, 영훈의 실용적 차림을 재단·관리 상태·소품으로 구별한다. 한복을 입히기 위해 직업적 맥락을 지우지 않는다. |

위 색상과 의상 배치는 제작 결정이다. 정확한 깃·저고리 길이·치마 구성·소매·신발·소재는 당대 사진과 유물 대조 후 확정한다. 현대 생활한복의 형태, 조선 후기 예복, 기모노·유카타를 기본 참고로 삼지 않는다. 기존 얼굴·헤어·인물별 색상은 이어가되 일률적인 일본 여학생 이미지를 만드는 교복·머리 장식을 피한다.

## 배경과 소품

- **푸른 집:** 평양 모란봉 가까운 주택이라는 위치를 구도에 반영한다. 담쟁이·붉은 벽돌 굴뚝·푸른 현관 기둥·흰 교차 지름길·라일락 등 원문 요소를 우선한다. 서양식 산장 같은 외형을 유지하면서 실내의 한국식 생활용품은 용도와 사료가 맞는 곳에 배치한다. 집 전체를 한옥으로 바꾸지 않는다.
- **대청·복도·방:** 원문의 붉은 주단과 축음기를 유지한다. 가구와 생활용품은 공간별 쓰임에 맞춰 검토한다. 목제 수납장, 옷 보관, 침구, 식기 등은 후보이며 특정 장·도자기·문살이 실제로 있었다고 확정하지 않는다. 다다미·쇼지·도코노마를 평양 집의 기본 문법으로 사용하지 않는다.
- **평양 거리:** 당시 평양 사진·지도에 근거한 건물 규모와 지형, 전차·상점·보행자의 복식을 사용한다. 한복과 양복·양장이 함께 보이게 한다. 간판의 언어와 표기는 당대 자료 확인 후 결정하며 식민지기의 일본어를 근거 없이 모두 지우지 않는다. 서울·교토·현대 평양의 경관을 그대로 가져오지 않는다.
- **백화점·영화관·음악 공간:** 근대적 설비를 유지하고 이용자 복식·가공 인쇄물·실내 생활 요소로 장소성을 전달한다. 한국적 분위기를 위해 피아노를 국악기로 바꾸거나 백화점을 전통 상점으로 바꾸지 않는다.
- **주을 노비나:** 한국의 산골 지형과 원문의 외국인 마을·별장이라는 특수성을 함께 반영한다. 한국적인 작품 방향을 이유로 한옥 마을로 치환하지 않는다.
- **도쿄·하얼빈:** 각 지역의 공간 특성을 유지한다. 한국적 정체성은 미란의 복식·소지품과 인물의 연속성에서도 드러나게 한다. 해외 배경을 한국식으로 통일하지 않는다.

## 색과 화면 구성

미란의 옥색·크림색, 세란의 가지색, 옥녀의 황토색·남색을 이어간다. 한복의 면과 겹침, 목재·벽돌·직물의 색 관계로 화면을 구성한다. 모든 장면을 강한 원색이나 전통 문양으로 덮지 않는다. 정원·집·거리·교습소·별장마다 조명과 경제적 환경의 차이를 유지한다.

스탠딩뿐 아니라 CG 속 의상, 배경의 인물, 표지·제목 화면의 삽화까지 같은 기준을 적용한다. 대화창·버튼은 가독성을 유지하며 장식 추가는 필요할 때 별도 검토한다.

## 후속 제작 순서와 검토 기준

1. 미란 기본 한복의 사진·유물 참고를 확보해 깃·소매·치마와 신발을 구체화한다.
2. 미란·세란·옥녀가 함께 있는 정원 CG와 각 스탠딩의 의상을 일치시킨다.
3. 정원·복도는 원문 건축 요소와 생활 소품을 검토하고, 시내 공간은 평양 사료를 우선한다.
4. 이후 에피소드의 가야, 피서 의상, 여행 의상과 해외 공간으로 확대한다.

검토할 질문: 장면의 지역·연대가 분명한가? 한국의 복식과 생활문화가 읽히는가? 계층·직업에 맞는 차이가 있는가? 서구 문화가 공존하는 원문의 세계가 유지되는가? 스탠딩과 CG가 일치하는가? 사료 근거와 창작 선택을 구분했는가?

이 문서만으로 새 이미지 생성은 시작하지 않는다. 현재 게임에 미술 변경이 적용되었다고 표시하지 않는다.
