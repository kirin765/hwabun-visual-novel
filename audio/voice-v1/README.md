# 화분 합성 발성 v1 · 이전 전자음 비교본

사용자 청취에서 전자음이 듣기 불편하다는 의견을 받아 현재 후보는 [짧은 사람 발성 v2](../voice-v2/preview.html)다. v1의 기본 음색은 전후 비교를 위해 유지했으며 실제 대사·자막은 수정된 1화와 맞췄다.

[비교 영상](episode1-comparison.mp4)과 [개별 비교 시청본](preview.html)을 제작했다. 파일을 브라우저로 열고 재생 버튼을 누른다. 네트워크·외부 라이브러리·로그인 없이 들을 수 있다. 한 번에 한 음원만 재생하며 ‘모두 중단’, 탭 숨김, 페이지 이탈 때 중단한다. 이름을 가린 비교의 정답은 접혀 있다.

먼저 미란·세란·단주·현마·옥녀의 같은 문장을 비교하고 실제 1화 대사를 듣는다. 이후 긴 반복과 합성 피아노·비 혼합으로 확인한다. 마지막에는 후속 인물·조연·라디오의 세 발성을 개별 확인할 수 있다. 비교 문장은 동일 조건을 위한 창작 문장이고 실제 1화 샘플은 `1화대본.md`의 연속 대화 블록에서 가져왔다. 긴 반복 샘플은 피로도 확인을 위해 실제 대사와 비교 문장을 조합한 청취용 텍스트다.

## 재생성

```sh
python audio/voice-v1/build.py
python audio/voice-v1/render-video.py
```

프로젝트 루트에서 실행한다. 음원 생성은 Python 표준 라이브러리만 사용한다. 영상 생성에는 설치된 FFmpeg와 Noto Sans CJK 글꼴을 사용한다. 고정 난수로 같은 결과를 만들고 이 폴더의 생성 파일을 갱신한다. `build.py`는 오프라인 음원 제작·검증 도구이며 게임 재생 코드가 아니다.

- 개별 발성: `{speaker}_{a|eo|eu}.wav`, 총 39개. 모노 PCM 24kHz·16bit.
- 비교 렌더: `*_common.wav`, `*_episode1.wav`, `miran_long.wav`, `miran_mixed.wav`, 총 13개.
- `manifest.json`: 공통 화자 ID·음색 파라미터·배역 초깃값·음원 목록·시청 문장.
- `verification.json`: 자동 검증 결과와 미확인 항목.
- `episode1-comparison.mp4`: 1화 다섯 인물의 같은 문장·실제 대사를 이름과 문장 자막으로 비교하는 비교 영상.
- `render-video.py`: 문장 WAV에서 영상 재생성.
- `preview.html`: 정적 비교 청취 페이지. 미리 듣기 설정만 제공한다.

합성은 기본음의 배음에 세 개의 공명대 가중치를 적용한다. 인물별 공명대 배율·배음 감쇠·길이로 구분하고 시작/끝을 완만하게 처리한다. 실제 발음을 복원하거나 성우를 모사하지 않는다. 라디오는 공통 낮은 발성의 배음을 약 330~2700Hz로 좁히고 작은 대역 제한 잡음을 섞는다. 외부 음원이나 녹음 파일은 사용하지 않았다.

개별 발성의 최대 피크는 약 0.18~0.21FS이며 비교 렌더에는 25% 게인을 적용했다. 비교 페이지의 25%는 이 기본 게인에 대응한다. 혼합 샘플은 진단용 합성 배경이고 프로젝트 BGM·환경음의 완성본이 아니다. 페이지에서 혼합 음원 음량을 바꾸면 배경도 함께 변한다. 게임의 별도 효과음 버스는 `장면구성.md`의 계약으로만 정의했다.

## 청취 기록

아래 항목은 **검토 대기**다. 자동 수치 검증을 청취 통과로 해석하지 않는다.

| 항목 | 상태 | 기록할 내용 |
|---|---|---|
| 얼굴 없이 다섯 인물을 구분 | 대기 | 틀린 쌍, 특히 단주/현마, 미란/옥녀 |
| 단주보다 영훈이 선명함 | 대기 | 배음·길이 차이가 전달되는지 |
| 긴 반복의 피로·희화화 | 대기 | 거슬리는 인물과 반복 길이 |
| 음악·비와 함께 균형 | 대기 | 튀거나 묻히는 소리; 실제 BGM 제작 후 재확인 |
| 후속 인물 음색 확정 | 대기 | 첫 다섯 인물의 청취 수정 후 재생성 |
| 엔진 동작 | 엔진 선정 후 | 속말/편지/선택지 무음, 즉시 표시/스킵/자동 진행/전환/메뉴 취소, 설정 꺼짐에서도 동일 진행 |

원본 대본을 오디오 데이터로 변환하거나 엔진을 선택하지 않았다. 재생 예약 취소와 개별 무음 처리는 제작 계약이며, 이 시청 페이지로 게임 동작을 검증한 것이 아니다.

검증 시 브라우저 연결이 없어 페이지의 실제 UI 조작은 확인하지 못했다. HTML 음원 경로·문서 링크·JavaScript 문법 검증은 통과했고 MP4 스트림과 자막 프레임을 확인했다.
