# 화분 · 짧은 사람 발성 v2

[비교 페이지](preview.html)에서 재생한다. [자막 비교 영상](episode1-comparison.mp4)은 약 26초다. 페이지의 첫 비교는 같은 문장을 v1 전자음과 v2 사람 발성으로 재생한다. 이어 이름을 가린 다섯 인물, 같은 문장, 실제 1화 대사, 긴 반복, 피아노·비 혼합, 후속 인물·조연 발성을 확인할 수 있다.

사용자의 확정 방향은 **대사 낭독 없이 짧은 사람 발성**이다. AI가 생성한 한국어 ‘아·어·으’의 연속된 짧은 부분을 사용한다. 기본음·배음·공명대로 만든 v1 전자음을 대체하며, 실제 사람의 녹음이나 음성 복제는 사용하지 않았다. v2는 청취 검토용 후보이며 자연스러움·인물 구분을 통과했다고 표시하지 않는다.

- 음원 39개: 모노 PCM WAV, 24kHz·16bit, 100~220ms 범위. 시작 12ms·끝 24ms 감쇠.
- 비교 음원 13개: 수정된 `1화대본.md`의 대사로 오프라인 렌더. 자막도 같은 데이터에서 생성한다. 게임에 연결할 문장별 낭독 음원이 아니다.
- 네 유효 글자마다 발성 기회, 최소 260ms 간격. 원음의 음높이·길이는 재생 중 그대로 유지한다. 25% 게인에서 음량만 작게 교대한다.
- 속말·서술·편지·선택지·제작 지시·개별 무음 블록에는 발성 없음. 기존 C01과 무음 지시는 유지한다.
- 같은 여성 기본 음성에서 생성 음높이를 조금 달리한 미란·세란·옥녀의 구분은 특히 청취 확인이 필요하다. 후속 인물은 확장 초안이다.
- 혼합 배경은 진단용 합성 피아노·비이며 실제 BGM·환경음의 완성본이 아니다.

음성 생성에는 [edge-tts](https://github.com/rany2/edge-tts)의 한국어 신경망 음성을 사용했다. 외부 서비스로 보낸 입력은 모음 ‘아.’·‘어.’·‘으.’뿐이며 대본·계정 정보는 보내지 않았다. 사용한 기본 음성과 생성 설정은 `manifest.json`에 기록했다. `sources/`에 생성 원본 MP3와 변환 WAV를 보관하므로 다시 들으며 추출 위치를 조정할 수 있다.

프로젝트 루트에서 재생성한다:

```sh
uv run --with edge-tts==7.2.8 python audio/voice-v2/build.py
python audio/voice-v2/render-video.py
python scripts/verify-episode1.py
```

첫 실행 또는 원본 MP3가 없는 경우에만 음성 생성 네트워크 요청을 한다. 원본이 있으면 비교 음원·페이지·영상은 오프라인으로 재생성된다. FFmpeg와 Noto Sans CJK 글꼴이 필요하다. 캐시된 원본을 사용한 렌더는 재현 가능하지만 외부 서비스에서 다시 생성하는 목소리까지 동일함을 보장하지 않는다.

자동 검증은 길이·끝점·클리핑·발성 간격·비발화 무음·자막과 대본 일치를 확인했다. MP4의 음성·영상 스트림과 한글 자막 프레임을 확인했다. 이 세션에는 연결된 브라우저가 없어 페이지의 실제 UI 재생·중단 조작은 확인하지 못했다. 게임 엔진 구현과 최종 청취 평가는 아직 수행하지 않았다.
